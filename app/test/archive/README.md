# アーカイブした自動検証

現在の仕様では使われていない機能の検証を、ここへ移した。`node --test test/*.test.js`（`app` で実行する現在の試験）はこのフォルダーを読まない。必要なときだけ、次で実行する。

```
node --test test/archive/*.test.js
```

| ファイル | 元の機能 | 外した理由 |
| --- | --- | --- |
| `debug-preview.test.js` | 中身のないデバッグ用の試験 | 検証がない。現在の仕様と関係しない。 |
| `graph-layout-arrange.test.js` | 「一括整列」（`graphControls` / `openGraphArrange`）と `GraphLayout.arrange` | 現在の画面には一括整列の操作がない（`ui-smoke` が `[data-graph-arrange]` の不存在を確認している）。旧関係図は位置のドラッグだけを残している。 |

## アーカイブしなかったもの

- 旧関係図・ノードで作る図・旧ステータス・旧タグ位置の検証は、既存データの表示と互換のため現在も必要なので残した。
- `pen`（関係を引くペン）は現在の画面に操作がない。専用の自動検証はなく、`ui-smoke` の「`[data-pen]` がない」確認だけが現在の仕様を守るため残している。
- 場所の「一覧／地図」の入れ子タブ（`bookview` / `view.場所`）は現在の画面に切替がない。手動監査 `test/ui-audit.cjs` に古い確認が1つ残っている（下記）。

## 手動監査から外した確認

`ui-audit.cjs` の「場所一覧／地図の入れ子タブ」の確認は、地図が独立したタブになった現在の仕様と合わないため外した。同じ場所は、地図タブそのもの（`data-book-tab="maps"` で `q` と絞り込みが隠れる）を確認する形に置き換えた。

## 戻すとき

アーカイブした検証は、機能を再び現在の仕様へ戻す場合だけ `test/` へ戻し、`node --test test/*.test.js` に含める。移動時は `require` の相対パス（`../../renderer/...`）を `../renderer/...` へ直す。
