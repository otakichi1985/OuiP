# OuiP -ウィップ-

未完成の創作を整理する、Windows向けの手元のアプリです。世界観・人物・用語・場所・年表をまとめ、関係図や地図、ボードで考えを整理できます。アカウントやサーバーは不要です。

## Windows版の使い方

対象は Windows x64。`ouip-win-x64-v0.2.0.zip` を展開し、`OuiP` フォルダー内の `OuiP.exe` をダブルクリックします。Node.jsのインストールは不要です。実行ファイルだけを取り出さず、フォルダー全体を保ってください。書き込み可能な場所へ展開してください。

創作データと保存履歴は「ドキュメント」の `OuiP` フォルダーに保存します。配布フォルダーとは別です。バックアップするときはアプリを閉じて、このデータフォルダーを隠しファイルも含めてコピーしてください。Chromiumの設定・キャッシュは別のアプリ設定領域に保存されます。

署名付きインストーラーではありません。Windowsが警告する場合があります。配布元を確認し、判断できない場合は実行しないでください。

ZIPの整合性は、同時に配布される `.zip.sha256` の値と、PowerShellの `Get-FileHash .\ouip-win-x64-v0.2.0.zip -Algorithm SHA256` の結果を比較できます。チェックサムだけで配布元の真正性を保証するものではありません。

## ボードを共有する

ボードへ設定カードやメモを並べ、「発表表示」で編集操作を隠して画面共有できます。「PNG 書き出し」はボード全体を画像にします。「共有を書き出す」は `.ouip-board` ファイルにし、受け手は0.2.0以降のOuiPで「共有を読み込む」を選ぶと、現在の世界とボードへ新しいカードとして追加できます。

共有ファイルには置いたカードの全文・タグ・設定項目・必要な画像・メモ・線が含まれます。世界全体や保存履歴は含みませんが、カード内の個人情報や未公開設定は自動で除かれません。書き出し前に内容を確認してください。共有ファイルは最大30MB、画像合計20MB、カード100件、ボード項目200件です。

## 更新時のフォルダー契約

`OuiP` は実行用ファイルだけの専用フォルダーです。創作データや個人ファイルを中へ置かないでください。

配布ZIPのトップレベルは必ず `OuiP/`。その直下に `OuiP.exe` と `.ouip-package.json` があり、マーカーは次の内容です。

```json
{"product":"OuiP","version":"0.2.0","platform":"win32","arch":"x64"}
```

「更新」からGitHubの正式リリースを確認し、ダウンロード・検証後に「更新して再起動」を選べます。編集を確定してから操作してください。配布元は `otakichi1985/OuiP`。ZIPのサイズとGitHubが提供するSHA256を検証し、アプリと同じボリュームの一時領域へ展開します。専用 `OuiP` フォルダーを兄弟の `OuiP.previous` へ退避して全体を交換します。旧版は1世代だけ保持され、次の更新で置き換えられます。「更新」から旧版へ戻すこともできます。ドキュメントの `OuiP` は入れ替え対象外です。

更新直前に創作データをアプリ設定領域の `updates` と並ぶ `data-backups` へ別途コピーします。旧版に戻す際、創作データを自動で巻き戻すことはありません。保存形式が変わった版から戻す場合は互換性に注意してください。更新失敗の記録はアプリ設定領域の `updates/update.log` に残します。自動的な定期通信は行わず、更新ボタンを操作したときだけGitHubへ接続します。開発版では入れ替えを無効にしています。

## 開発とローカル配布物の作成

開発にはNode.jsとnpmが必要です。アプリはElectron 44.7.0、保存履歴はisomorphic-gitを使用します。

```powershell
cd app
npm ci
npm test
npm start
```

リポジトリのルートで実行します。

```powershell
node scripts/package.cjs
node scripts/prepare-public.cjs public-source-v0.2.0
```

配布スクリプト自体は取得を行いません。インストール済みの `app/node_modules/electron/dist` をコピーし、`electron.exe` を `OuiP.exe` に変更します。`resources/app` は `main.js`、`preload.js`、`lib/`、`renderer/`、`package.json` と、lockfileで `dev` が `true` ではない本番依存だけです。Electron・Chromiumと各依存のライセンスファイルを保持します。Windows標準の `System32/tar.exe -a` でZIPを作り、マニフェスト照合とSHA256計算を行います。

出力は `dist/OuiP/`、ZIP、チェックサムです。再実行すると該当出力を作り直します。公開ソースは指定した `dist/public-source-v0.2.0/` に、アプリのソース・テスト・package-lock・配布スクリプト・このREADME・リリースノートだけを書き出します。引数なしは `dist/public-source/` ですが、出力先に `.git` があれば停止し、既存の公開リポジトリを保持します。新版は別のステージング先へ書き出して確認し、公開リポジトリへ変更を移してください。`node_modules`、内部資料、試作、Git管理情報、利用者データは含めません。個人の絶対パスや代表的な認証情報のパターンが見つかれば停止します。ただしパターン検査は秘密情報の不存在を完全には証明できないため、公開前に内容の確認が必要です。Git初期化・コミット・アップロードは行いません。

本プロジェクトのソースに対する公開ライセンスは未設定です。依存ソフトのライセンスとは別に扱ってください。
